# Content Rules

1. Never use dash characters (hyphen `-`, en dash `–`, em dash `—`) as separators or punctuation in visible content: titles, descriptions, captions, and body copy. Rewrite with commas, colons, or periods instead.
   - Exceptions: SEO titles, browser tab titles, and meta tags.
2. All copy comes from data or config files, never hardcoded inside components.
3. Write in clear, concise, plain language. No filler or buzzwords.
4. Use consistent terminology for the same thing across the whole site.
